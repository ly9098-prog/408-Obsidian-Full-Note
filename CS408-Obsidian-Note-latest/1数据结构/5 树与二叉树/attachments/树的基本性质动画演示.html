根、深度与层次

记忆钩子

九个术语，一屏速记

先看关键词，再在脑中定位到上方示例树。
结点的度

该结点拥有的子树数。例：A 有 3 个孩子，所以 degree(A)=3。

叶子

度为 0 的结点。示例中 E、F、H、I、J 都是叶结点。

分支结点

度不为 0 的结点。只要还能“向下分叉”，就是分支结点。

树的度

树中所有结点度数的最大值。本树最大为 3，因此树的度是 3。

层次

根结点层次为 1；其余结点层次等于双亲层次加 1。

树的高度

树中结点的最大层次。本树共 4 层，所以树高为 4。

无序树

兄弟子树之间的次序不重要，交换位置后仍视为同一棵树。

有序树

兄弟子树之间的次序有意义，交换位置可能得到不同的树。

森林

由 0 棵或多棵互不相交的树组成；删除一棵树的根可得到一个森林。

高度、深度、层次：最容易混的三件事

方向不同，计数起点也不同。
⬇

结点高度

从该结点向下到叶结点的最长路径长度，按“边数”计。叶结点高度为 0。

⬆

结点深度

从根结点向下走到该结点所经过的边数。根结点深度为 0。

≡

结点层次

层次 = 深度 + 1。因此根结点层次为 1，而不是 0。
