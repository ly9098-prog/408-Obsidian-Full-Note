4C 语言代码逐行对照

带头结点：按位插入

bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false;

    LNode *p = L;       // p 从头结点开始
    int j = 0;

    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    if (p == NULL) return false;

    LNode *s = (LNode *)malloc(sizeof(LNode));
    if (s == NULL) return false;

    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}

当 i=1 时，p 就是头结点，因此不需要额外判断。

不带头结点：按位插入

bool ListInsert(LinkList *L, int i, ElemType e) {
    if (i < 1) return false;

    LNode *s = (LNode *)malloc(sizeof(LNode));
    if (s == NULL) return false;
    s->data = e;

    if (i == 1) {         // 首位插入特殊处理
        s->next = *L;
        *L = s;            // 修改头指针
        return true;
    }

    LNode *p = *L;
    int j = 1;
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    if (p == NULL) {
        free(s);
        return false;
    }

    s->next = p->next;
    p->next = s;
    return true;
}

函数可能改变头指针，所以传入头指针的地址：LinkList *L。

为什么必须先执行 s->next = p->next？

若先执行 p->next = s，原后继结点的地址会丢失；随后再令 s->next = p->next，实际上会让 s 指向自己，形成自环。

考试口令：先接后面，再接前面；即“新结点先指后继，前驱再指新结点”。

5408 高频判断与易错点

① 头结点不是首元结点

头结点通常不存放有效数据；首元结点才存放第一个数据元素。

② 带头结点不代表头指针不会变

一般插入删除时 L 不变，但创建、销毁或整体替换链表时仍可能改变 L。

③ 插入位置的合法范围

长度为 n 的线性表，可插入位置通常为 1 ≤ i ≤ n+1。

④ “找到第 i 个结点”是错位思维

插入要先找到第 i−1 个结点（前驱），再修改两条 next 指针。

⑤ 不带头结点时，i=1 无前驱

因此不能套用普通前驱插入，必须直接令新结点成为新的首元结点。

⑥ 复杂度不要被头结点迷惑

头结点简化边界处理，但不改变按位查找的渐进时间复杂度 O(n)。

63 题快速自测

1. 带头结点的空单链表 L 满足：

A. L == NULL
B. L != NULL 且 L->next == NULL
C. L->data == NULL
D. L->next == L
答案 B。L 指向头结点，空表只是头结点之后没有数据结点。

2. 不带头结点的单链表在第 1 位插入时，最关键的特殊操作是：

A. 找到尾结点
B. 令原首元结点指向新结点
C. 修改头指针，使其指向新结点
D. 删除原首元结点
答案 C。先令 s->next 指向原首元结点，再令 L 指向 s。

3. 已知 p 是插入位置的前驱，正确的语句顺序是：

A. s->next=p->next; p->next=s;
B. p->next=s; s->next=p->next;
C. p=s; s->next=p->next;
D. s=p->next; p=s;
答案 A。顺序反过来会丢失原后继地址，并可能形成自环。
带头结点：首位也统一；不带头结点：首位改头指针。
插入两句话：s 接后继，p 接 s。
