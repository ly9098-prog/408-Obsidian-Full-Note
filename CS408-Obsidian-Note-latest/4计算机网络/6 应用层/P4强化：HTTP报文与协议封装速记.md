# P4强化：HTTP报文与协议封装速记

> 来源：用户提供的《计网P4：各层协议封装串讲、路由选择协议》；本页只提取考研 408 复习要点。

## HTTP 请求/响应报文

### 请求报文

```text
请求行：方法  URL  版本  CRLF
首部行：字段名: 值  CRLF
        ...
空行：CRLF
实体主体：可选
```

### 响应报文

```text
状态行：版本  状态码  短语  CRLF
首部行：字段名: 值  CRLF
        ...
空行：CRLF
实体主体：可选
```

- 常见方法：`GET` 获取资源，`POST` 提交/上传数据，`HEAD` 只请求资源首部。
- 常见状态码：`200` 表示请求成功，`404` 表示请求的 URL 资源不存在；状态码只需掌握常见含义。
- 请求报文的实体主体通常由 `POST` 等方法携带；`GET` 例题中常为空。
- HTTP 使用 TCP 承载：应用数据交给 TCP 后，再按 TCP MSS 分段；HTTP 本身无连接、无状态，不能把“使用 TCP”误解成“HTTP 自身面向连接”。

## 一次 Web 访问的协议链

```text
HTTP 请求/响应
  -> TCP 报文段
  -> IPv4 数据报
  -> 以太网 MAC 帧
```

DNS 查询通常先用 UDP/53 获得服务器地址，随后 HTTP 使用 TCP/80 建立连接。各层首部分别由对应层添加，接收端按相反顺序解封装。
