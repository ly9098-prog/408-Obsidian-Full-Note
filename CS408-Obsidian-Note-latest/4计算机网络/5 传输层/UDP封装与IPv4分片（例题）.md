# UDP封装与IPv4分片（例题）

> [!important] 先分清层次
> UDP 数据报交给 IP 层后，过长的 IPv4 数据报可在**允许分片**时被分片。分片发生在**网络层**；这里放在 UDP 笔记旁，用于理解封装关系。

## 1. 题设与封装长度

原图题设：应用数据 **3200 B**，UDP 首部 **8 B**，IPv4 首部 **20 B**，链路 **MTU = 1500 B**。按原图执行分片，即按允许分片处理。

```text
应用数据                         3200 B
UDP 数据报 = UDP 首部 + 应用数据   8 + 3200 = 3208 B
IP 数据报 = IP 首部 + UDP 数据报   20 + 3208 = 3228 B
```

- **UDP 数据报整体是 IP 载荷**，其中包含 UDP 首部。
- 本例 IP 首部为 20 B；首部长度字段 IHL 以 **4 B** 为单位，所以 **IHL = 5**。
- 图中各报文框宽为示意，**不按字节数比例绘制**。

## 2. MTU 限制什么

**MTU 限制链路承载的 IP 分组长度：IP 首部 + IP 载荷。**

- `3228 > 1500`，原 IP 数据报不能作为一个完整分组装入本例链路的帧。
- 每个分片都带一个独立的 **20 B IP 首部**。
- 本例单片载荷上限：`1500 - 20 = 1480 B`。
- 除最后一片外，分片载荷必须是 **8 B 的整数倍**；本例 `1480 / 8 = 185`。

一般计算式（首部长度按题设取值）：

$$
L_{\text{非末片最大载荷}}
= 8 \left\lfloor \frac{\mathrm{MTU}-H_{\mathrm{IP}}}{8} \right\rfloor
$$

> [!note] MTU 与以太网帧长度
> 原图以太网帧写成 `6 + 6 + 2 | IP 分组 | 4`，分别表示目的 MAC、源 MAC、类型字段，以及末尾的 FCS，单位均为 B。**帧首部的 14 B 和 FCS 的 4 B 不占本例 MTU 的 1500 B。**

## 3. 分片例题

先切分 **3208 B 的 IP 载荷**：

`3208 = 1480 + 1480 + 248`，共 **3 片**。

| 分片 | 原 IP 载荷的字节范围（从 0 编号） | 本片载荷 | IP 总长度 | 片偏移字段 | MF |
| --- | --- | ---: | ---: | ---: | ---: |
| 第 1 片 | 0～1479 | 1480 B | 1500 B | 0 | 1 |
| 第 2 片 | 1480～2959 | 1480 B | 1500 B | 185 | 1 |
| 第 3 片 | 2960～3207 | 248 B | 268 B | 370 | 0 |

### 片偏移怎么算

**片偏移 = 本片载荷在原 IP 载荷中的起始字节位置 / 8。**

- 第 1 片：`0 / 8 = 0`。
- 第 2 片：`1480 / 8 = 185`。
- 第 3 片：`(1480 + 1480) / 8 = 370`。
- 起点相对于**原 IP 载荷**，不包含原 IP 首部，也不把分片新增的 IP 首部累计进去。

### 首部字段记忆

- 三片的 **Identification（标识）相同**，原图没有给出具体标识值。
- **IHL 都为 5**，对应本例各片的 20 B IP 首部。
- **MF = 1**：后面还有分片；**MF = 0**：后面没有分片，本例第 3 片为末片。
- IPv4 的 DF 表示是否禁止分片；本例按允许分片，即 **DF = 0** 处理。

## 4. 易错点

- **分的是 IP 载荷。** 不是把应用数据 3200 B 直接切成三片；应先包含 UDP 首部，得到 3208 B。
- **UDP 首部只出现一次。** 它位于第 1 片的 IP 载荷开头，不给每一片重新加 UDP 首部。
- **每片都要加 IP 首部。** 第 3 片 IP 总长度为 `20 + 248 = 268 B`，不是 248 B。
- **片偏移字段的单位是 8 B。** 答案为 `0、185、370`，不是 `0、1480、2960`。
- **非末片的载荷才必须按 8 B 对齐。** 本例末片 248 B 也恰好是 8 的倍数，不能由此推断末片必须如此。
- **MTU 包含 IP 首部，不包含以太网帧首部和 FCS。**
- 原图的过程是 **UDP 报文封装后由 IP 层分片**，不要混写成 UDP 按 TCP 的 MSS 分段。
