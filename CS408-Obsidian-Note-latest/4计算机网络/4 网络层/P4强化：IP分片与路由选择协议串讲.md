# P4强化：IP 分片与路由选择协议串讲

> 来源：用户提供的《计网P4：各层协议封装串讲、路由选择协议》；用于补充 IPv4 分片、RIP/OSPF/BGP 的过程型考点。

## 1. IPv4 分片与再分片

- IPv4 分片由网络层根据**下一跳出接口 MTU**决定；IP 载荷 = 原 IP 数据报数据部分（包括 UDP 首部等传输层内容）。
- 非末片载荷必须是 8 B 的整数倍；片偏移单位为 8 B，起点始终相对于**原始未分片 IP 载荷**。
- 同一原始数据报的所有分片保持相同 Identification；MF=1 表示后面仍有分片，MF=0 表示最后一片。
- 分片可以在沿途多个路由器上继续发生；中间路由器不重组，最终目的主机才重组。
- 若 DF=1 且分组超过下一跳 MTU，路由器不能分片，应丢弃并返回 ICMP 差错报告。

### 再分片示例

原始 IP 总长度 3228 B，先经 MTU=1500 B 链路形成载荷 `1480/1480/248` 三片；若下一跳 MTU=796 B，则非末片最大载荷为 `776 B`：

- 原第 1 片：`1480=776+704`，形成总长度 796、724，片偏移 0、97，MF 均为 1。
- 原第 2 片：父片偏移 185，子片偏移为 `185+0=185`、`185+97=282`，总长度 796、724，MF 均为 1。
- 原第 3 片：248 B 载荷可原样转发，总长度 268，片偏移 370，MF=0。

## 3. RIP 过程型考点

### 基本规则

- 到直连网络的距离记为 1；距离 16 表示不可达。
- RIP 按周期交换距离向量；题设若未启用触发更新、水平分割和毒性逆转，则坏消息会在邻居的过期信息之间逐步传播。
- RIP 路由表属于控制平面，可能保留距离、更新时间和等价候选路径；路由转发表是从中选出最佳路由后供数据平面实际转发使用。

### 收敛时间

- 首次启动后的全 AS 收敛时间看最远网络可达信息传播了多少条路由器间链路。本题拓扑中最远为 3 条链路，周期为 30 s，因此至少 `60 s`。
- 新链路接通并在周期更新开始前立即交换时，新的更小距离可直接采用；随后再用一次周期传播，至少 `30 s`。若错过一次周期更新，实际等待可能接近 `60 s`。
- 好消息传播快：收到更小距离即可更新。坏消息传播慢：邻居仍缓存旧距离，会互相构造出依赖失效链路的替代路径，距离逐轮增大。

### 失效链路的典型推理

直连 Net2 的 R2 失效后，若 R1、R4、R5 仍通告旧距离 2，则 R2 会计算 `min(16,2+1,2+1,2+1)=3`，错误地认为可经邻居到达 Net2；其更新继续传播后，R1/R4/R5 仍可能暂时保留距离 3 等错误路径。这是“坏消息传得慢”的根源。

## 4. OSPF 过程型考点

### 启动到收敛

1. 接口初始化，形成直连路由。
2. 相邻路由器建立 OSPF 邻居关系。
3. 生成并泛洪 LSA；同一 Area 内路由器建立基本一致的 LSDB。
4. 每台路由器以自己为根独立运行 Dijkstra 最短路径算法。
5. 由计算结果生成本机路由表，再生成供数据平面使用的转发表。

### 三者区别

- LSDB：保存 Area 内链路状态和网络可达信息，同一 Area 收敛后基本一致。
- 路由表：以本机为根计算出的最优路由集合，包含目的网络、开销、下一跳、出接口；不同路由器可不同。
- 转发表：从路由表提取目的前缀、下一跳和出接口，用于逐个 IP 分组转发，不保存完整拓扑。

### 拓扑变化

- 新链路接通：立即建立邻居并触发 LSA 泛洪，所有路由器更新 LSDB、重新运行 Dijkstra，快速切换到低代价路径。
- 直连网络失效：相关路由器发布不再包含该网络的新版 LSA；全 Area 更新后，各路由器都能判断该网络不可达，不会出现 RIP 式的“坏消息传得慢”。
- Area 划分可减少洪泛范围和各路由器 LSDB 规模；主干区域为 Area 0。

## 5. BGP 过程型考点

- BGP 是 AS 之间的外部网关协议，目标是找到“较好”而非绝对最短的 AS 间路径；策略可能受政治、安全和经济因素影响。
- BGP 是路径向量协议，通告中包含目的网络的 CIDR 前缀、AS-PATH、NEXT-HOP 等属性。
- BGP 邻居先建立 TCP 连接，再交换 BGP 报文；eBGP 位于不同 AS 边界路由器之间，iBGP 位于同一 AS 内部。
- iBGP 学到的路由不能再通过 iBGP 传播给其他 iBGP 邻居，以避免环路；AS 内 iBGP 经典要求全连接，N 台路由器形成 `N(N-1)/2` 条会话。

### BGP 选路顺序（题设常用）

1. 选择本地偏好值最高的路线。
2. 若相同，选择 AS-PATH 最短的路线（AS 跳数少不代表路由器跳数少）。
3. 若仍相同，使用热土豆路由：依据本 AS 内部网关协议，以最小代价离开本 AS。
4. 若仍相同，选择 BGP 标识符 BGP ID 最小的路由。

### 四类 BGP 报文

- Open：建立会话并完成初始化。
- Update：通告新路由或撤销路由。
- Keepalive：周期性保活。
- Notification：报告错误并关闭会话。
