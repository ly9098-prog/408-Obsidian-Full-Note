循环队列的实现：方法二与方法三

参考环形队列示意图重新绘制。容量 MaxSize = 6，rear 指向“下一次入队位置”。

方法二增加 size 计数器

size 直接记录队列中当前元素个数，因此即使 front 与 rear 重合，也能判断是空还是满。
front
rear
size
队空：size == 0
队满：size == MaxSize
入队：rear = (rear + 1) % MaxSize，size++
出队：front = (front + 1) % MaxSize，size--

方法三增加 tag 标志位

tag 记录最近一次操作：入队后设为 1，出队后设为 0。front == rear 时，由 tag 区分空和满。
front
rear
tag
约定：入队后 tag = 1，出队后 tag = 0
队空：front == rear && tag == 0
队满：front == rear && tag == 1
当 front != rear 时，队列一定既不空也不满。
